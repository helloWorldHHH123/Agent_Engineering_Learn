
# <span style="color: #E57373;">1. OpenAI Agents SDK：多轮对话记忆管理</span>
### 一、代码功能

代码通过 `**result.to_input_list()**` **保存历史对话，并在下一次调用 Agent 时传入历史记录**，实现多轮对话中的上下文记忆。

使 Agent 能够根据之前的对话内容理解当前问题，而不是将每次提问作为独立的问题处理。

### 二、关键处理流程

**1. 第一轮：调用 Agent**

```
result = await Runner.run(agent, '1+1=？')
```

异步调用 Agent，模型回答 `2`。

**2. 获取历史对话记录**

```
history = result.to_input_list()
```

将本轮运行的输入和输出转换为 Python 列表，保存用户问题和模型回答。

**3. 添加新的用户问题**

```
history.append({"role": "user", "content": "再+1=？"})
```

将新问题添加到历史对话中，形成包含上下文的消息列表。

**4. 第二轮：携带历史记录调用 Agent**

```
result = await Runner.run(agent, history)
```

将完整的历史消息传递给 Agent，使模型根据前面的计算结果 `2` 理解“再加1”，最终回答 `3`。

**5. 获取更新后的完整对话**

```
print(result.to_input_list())
```

输出第二轮执行结束后的完整对话记录，便于查看或继续进行后续交互。

### 三、完整执行流程

```
用户第一轮提问：1+1=？
          ↓
Runner.run() 调用 Agent
          ↓
LLM 回答：2
          ↓
result.to_input_list()
获取历史对话记录
          ↓
history.append()
添加第二轮问题：再+1=？
          ↓
Runner.run(agent, history)
携带历史记录再次调用 Agent
          ↓
LLM 根据历史上下文回答：3
          ↓
result.to_input_list()
获取更新后的完整对话
```

### 四、核心总结

代码实现的是 **基于对话历史列表的短期记忆（Short-term Memory）**。

关键在于三个操作：

1. **获取历史**：`result.to_input_list()`。
    
2. **更新历史**：`history.append()`。
    
3. **利用历史**：`Runner.run(agent, history)`。
    

历史列表还可以进行截断、摘要压缩和语义检索等处理，以控制上下文长度。

**核心思想：Agent 默认不会在彼此独立的运行之间自动继承全部对话历史，需要通过保存并重新传入历史消息，让模型具备多轮对话的上下文理解能力。**

注意：这里实现的是程序运行期间的对话历史管理，并没有将记忆持久化保存到磁盘或数据库中。

# OpenAI Agents SDK：多模态图片输入

## 一、代码功能

代码实现：**读取本地图片 → Base64 编码 → 构造多模态消息 → 异步调用 Agent → 获取模型回答。**

目的是让支持视觉能力的大模型根据用户提供的图片和文字问题进行分析。

## 二、核心代码解析

### 1. 创建 Agent

```
agent = Agent(
    name="AI助手",
    instructions="你是一个友好的AI助手。使用中文进行回答",
    model="deepseek-flash",
)
```

通过 `Agent()` 创建智能体，设置系统提示词和模型名称。

### 2. 图片 Base64 编码

```
def encode_image(image_path):
    with open(image_path, "rb") as image_file:
        bin_content = image_file.read()
        return base64.b64encode(bin_content).decode("utf-8")
```

作用：

- `open(image_path, "rb")`：以二进制只读方式打开图片。
    
- `image_file.read()`：读取图片的二进制数据。
    
- `base64.b64encode()`：将二进制数据编码为 Base64。
    
- `.decode("utf-8")`：转换成 Python 字符串。
    

**本质：将本地图片转换成便于通过 API 传输的文本数据。**

### 3. 构造多模态消息

```
base64_image = encode_image("AIAgent2.png")

messages = [
    {
        "role": "user",
        "content": [
            {
                "type": "input_image",
                "image_url": f"data:image/png;base64,{base64_image}",
            }
        ],
    },
    {
        "role": "user",
        "content": "图片中是什么内容？是什么颜色？",
    },
]
```

关键字段：

|字段|作用|
|---|---|
|`role`|指定消息发送者为用户|
|`content`|存放消息内容|
|`type: input_image`|表示图片输入类型|
|`image_url`|存放图片地址或 Base64 Data URL|
|`base64_image`|保存图片编码后的字符串|

其中 `input_image` 是 OpenAI Responses 风格的固定输入类型，不是自己定义的。

### 4. 异步调用 Agent

```
result = await Runner.run(agent, messages)
print(result.final_output)
```

- `Runner.run(agent, messages)`：将多模态消息传入 Agent。
    
- `await`：异步等待 Agent 运行完成。
    
- `result.final_output`：获取最终回答。
    

## 三、核心处理流程

```
程序启动
    ↓
加载 API 配置
    ↓
Agent() 创建智能体
    ↓
读取本地图片 AIAgent2.png
    ↓
encode_image()
    ↓
读取图片二进制数据
    ↓
Base64 编码并转换为字符串
    ↓
构造 messages 消息列表
    ├── 图片消息（input_image）
    └── 文本问题（user）
    ↓
await Runner.run(agent, messages)
    ↓
Agent 将请求发送给模型
    ↓
模型理解图片并生成回答
    ↓
result.final_output
    ↓
打印最终结果
```

## 四、关键知识点

1. **Base64 编码**：将图片二进制数据转换为可放入 JSON 消息的字符串；它不是图片压缩。
    
2. **多模态消息**：`content` 可以包含不同类型的输入，例如文本和图片。
    
3. **固定协议格式**：`input_image`、`image_url` 等字段需要遵守对应 API 的输入规范。
    
4. **异步调用**：`await Runner.run()` 等待 Agent 执行完成，并返回运行结果。
    
5. **模型能力限制**：消息格式正确不等于模型一定能够识别图片，还需要模型和 API 接口支持视觉输入。
    

## 五、注意事项

- 图片为 `.png` 时，应使用 `data:image/png;base64,...`，而不是 `image/jpeg`。
    
- `input_image` 属于 OpenAI Responses 风格的输入格式；直接使用 Chat Completions API 时，图片消息通常采用 `type: image_url`。
    
- 当前代码通过本地配置使用 DeepSeek 的 Chat Completions 接口，实际能否识别图片还取决于所选 DeepSeek 模型的视觉能力及接口兼容性，不能只根据代码格式判断。
    

## 六、一句话总结

**多模态 Agent 图片输入的核心流程是：读取图片 → Base64 编码 → 构造图片与文本消息 → 调用 Agent → 获取模型分析结果。**

        },  # 第一条用户消息结束  
  
        {  # 第二条消息：传递文字提示词  
            "role": "user",  # 消息角色：用户  
            "content": "图片中是什么内容？是什么颜色？",  # 用户提出的问题，让大模型分析上面的图片  
        },  # 第二条用户消息结束  
    ]  # 消息列表结束  
    result = await Runner.run(agent, messages)     # 异步写法  
    print(result.final_output)  
    # result = await Runner.run(agent, "1+1等于多少？")
